Загрузка выгрузки чата

Загрузи result.json (экспорт чата из Telegram) и, при необходимости, PDF-файлы резюме, на которые он ссылается. Обработка идёт на сервере: парсинг PDF, LLM-экстракция полей и фидбэка — это может занять несколько минут на большой выгрузке.

Файл выгрузки чата, без изменений.
Выбери папку files/ рядом с result.json — все PDF внутри будут загружены (остальные файлы в папке пропускаются автоматически). Если её не указать, сервер будет искать уже существующие файлы у себя на диске.
Обрабатываем на сервере — не закрывай страницу…
